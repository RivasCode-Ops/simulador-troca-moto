# MI00 — Conteúdo bruto

## CONTEXTO

```
Como surgiu a ideia: Tenho moto de 1 ano, quero outra mais nova, mas não tenho o valor total.
Tipo de material: texto solto (copy da conversa)
Objetivo desta sessão: estruturar a ideia e ter ferramenta para simular a troca com mínima perda
Restrições: não consigo comprar a moto nova à vista; preciso vender a atual financiada para terceiro
```

## MATERIAL BRUTO

```
Tenho uma moto de um ano e quero comprar outra, mas não tenho o dinheiro todo.
A solução que pensei foi financiar uma moto nova vendendo a atual de forma financiada para outra pessoa.
A moto hoje vale 25.000.
O novo comprador entra com 20.000 à vista e os 5.000 restantes seriam financiados, com juros de mercado.
A moto nova custa 30.000.
Com isso, eu usaria os 20.000 que recebi como entrada na concessionária e financiaria o saldo de 10.000 da moto nova, com os juros do financiamento normal.
Quero uma forma de fazer essa matemática para praticar a venda e perder o mínimo possível, já que não posso comprar a moto nova à vista.
```
